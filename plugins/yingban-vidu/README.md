# 映伴 · Vidu 视频

版本 0.4.0，本机真实接口候选版。独立开发，非 Vidu 官方出品；尚未公开上架。

支持官网账号连接、文生视频参数设置、真实积分预估、用户确认后提交、查询生成结果。接口适配参考 [Vidu 官方开源 CLI](https://github.com/shengshu-ai/vidu-cli)，使用官网 Vidu Token，不是开放平台 API Key。

本包没有模拟模式、模拟余额、模拟订单或模拟视频。不提供套餐销售、支付核验或自动注册。开发环境已验证真实赠送积分生成视频，但不等于已完成公开商用验收。

## 本机安装

需要 Codex 桌面版、PATH 中的 `uv`、Edge/Chrome，以及 Windows 凭据管理器、macOS Keychain 或 Linux Secret Service。运行时使用 Python 3.12，uv 首次启动会准备锁定的依赖，需要网络连接。

插件由项目中的 `scripts/build_plugin.py` 构建，通过 `.agents/plugins/marketplace.json` 提供本地安装。添加市场：`codex plugin marketplace add <项目绝对路径>`；安装：`codex plugin add yingban-vidu@yingban-local`。其他支持 MCP 的桌面智能体可使用 `mcp.json` 所定义的 stdio 进程，将插件路径变量替换为安装路径。此包不提供云端 HTTPS 服务。

在 Codex 插件页选择“映伴 · 本机插件”，搜索“映伴”或 `yingban-vidu`。已有窗口可能需要刷新或重启后才能加载新增 MCP 工具。新对话可说：“连接我的 Vidu 账号”。

首次连接自动启动本机登录助手与独立的无头浏览器，打开官方登录面板。用户在面板中登录或注册，然后点击「我已登录，授权并连接」。不需要复制 Token。面板入口只监听 `127.0.0.1`，五分钟内使用一次；交互会话最长十五分钟。用户确认授权后，服务验证官网授权并保存到系统凭据库，凭据不会经由 MCP 返回给智能体。后续调用自动读取授权；失效时需要重新连接。

不需要手工运行登录服务、填端口或配置浏览器映射。无活跃面板且闲置 30 分钟后助手关闭，下次连接自动启动；专用浏览器配置目录保留登录状态。已经登记且仍可用的配套服务会继续复用。Windows 默认账号目录为 `%LOCALAPPDATA%\Yingban\YingbanVidu`；登录助手与插件共用同一个账号存储，断开授权使旧面板失效。账号存储不一致或浏览器缺失时给出错误，不回退手动 Token 表单。

生成前显示配置和真实积分费用，等待确认。外部充值或连接成功都不会自动生成。提交结果不明确时不自动重试。

## 数据和权限

Vidu 授权只保存在操作系统凭据库，并通过 HTTPS 发给 Vidu 服务。官方登录面板当前使用国际站。面板转发官方页面画面和用户输入；用户点击授权后，服务读取官网展示的视频授权并验证，凭据画面不会回传到智能体。视频描述仅在用户确认提交时发给 Vidu；费用预估不发送描述。不读取 Codex 账号、浏览器 Cookie 或剪贴板。

视频描述、配置、任务编号和返回的视频链接保存在本机应用数据目录的 SQLite 文件中，未额外加密，也不会上传到本插件开发者的服务器。Windows 默认目录是 `%LOCALAPPDATA%\Yingban\YingbanVidu`，其他系统由 platformdirs 选择标准应用数据目录。数据保留至用户主动删除；先停止插件，再删除该目录可清理工作流记录。执行“断开 Vidu 账号”删除系统凭据并使旧账号工作流失效，但保留本地历史文件，也不会取消已提交任务或官网订阅。取消安装插件不会自动删除凭据，请先断开账号。

本机安装不会使插件自动进入公共目录。公开发布还需要接入授权、正式认证服务、公开 HTTPS MCP、发布者资料、隐私/支持/条款页面及审核。公共目录当前不允许销售数字订阅或积分。
